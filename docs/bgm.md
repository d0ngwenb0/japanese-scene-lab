# 背景音乐

全站背景音乐：**一首连续的轻快原声器乐**，约 2 分 49 秒，无缝循环，默认关闭，用户手动开启。

## 曲目

| 文件 | 时长 | 说明 |
|---|---|---|
| `light-breeze.mp3` | 2:49 | 轻快原声器乐：木吉他指弹、温暖 Rhodes 电钢琴、轻巧马林巴/钟琴点缀与柔和刷鼓节奏 |

首尾都在 −55dB 以下自然收束，所以直接 `loop` 循环不会有明显接缝，没有做任何拼接。

## 怎么生成的

- 模型：**Google Lyria 3 Pro**（`lyria-3-pro-preview`），`generateContent` + `responseModalities: ["AUDIO"]`
- 一次调用生成整段，提示词要求 G 大调、100 BPM、轻快松弛的咖啡馆/学习氛围、木吉他与电钢琴搭配轻柔点缀、无 vocals、首尾平稳淡入淡出
- **输出原样使用**：192kbps 立体声 44.1kHz MP3，约 3.9MB，不做裁剪、不做交叉淡化、不做响度归一
- Key 只从 `.env.local` 读取，不进仓库、前端或构建产物

要换曲子，直接重新生成并覆盖 `public/bgm/light-breeze.mp3` 即可，代码里只引用这一个文件名。

## 播放方式

- 开启后淡入 2 秒，音量稳定在 `0.04`
- `audio.loop = true` 无限循环，曲尾本来就是安静的，接回曲首听不出断点
- 切场景不重新加载，播放状态跨页面保持
- 默认关闭，选择记在 localStorage（`settings.bgm`）
- 浏览器拦截自动播放时，等用户第一次点击或按键后补播
- 文件在 `public/bgm/`，会被 PWA 预缓存
