# Scene Lab 需求与验收清单

最后更新：2026-11-14

这份清单是长期约束。以后每次改动都按它自查，不要求用户重复。

## 产品形态

- 私人日语场景训练 PWA，桌面和手机都能用
- 纯静态，部署在 GitHub Pages
- 源码仓库只在本地；公开仓库只放 `dist`
- 支持安装到主屏幕、离线使用
- 只发静态站，不引入后端服务

## 场景与界面

- 场景列表、逐句高亮、假名注音、中文翻译
- 单句循环、整段/整篇循环
- 0.75× / 1× / 1.25× 速度
- 复制单句、复制整段
- 深色模式
- 明暗和主题是两个独立按钮：明暗控制自动/浅色/夜间，主题控制原色/樱/青竹/海，可自由组合
- 网页全屏：首页和播放页顶栏提供网页全屏按钮与 `F` 快捷键，支持原生 Fullscreen API 并在不支持的环境下回退到网页铺满模式（`Esc` 优先退出全屏）
- 列表 / 卡片两种视图，首页默认卡片模式
- 列表标题的 ruby 不能拥挤：字体、颜色、行高、间距都要协调
- 首页按场景分类与类型（对话/短文）筛选；同一维度互斥，不同维度叠加
- 已移除 JLPT 等级标签、难度排序/筛选及有/无音频状态切换
- 搜索功能已移除
- 进度环、进度筛选、进度记忆已移除
- 吉祥物已移除
- 自然音徽标和绿色小点已移除
- 场景切换：上一个 / 下一个、场景菜单，按钮带文字标记
- 每段对话必须逐轮检查问答关系：提问有回答、请求有处理、信息不前后矛盾；改日文后台词与音频不得继续错配
- 首页提供「随机学」：从当前筛选结果随机打开场景，连续点击不立即重复
- 播放页场景导航提供随机切换，不随机到当前场景
- 进度、问 AI、复制整段放在工具条；宽屏左对话、右 AI 解析，分隔条可拖动调整宽度（双击复位，方向键微调）
- 假名和中文始终显示，不提供关闭开关
- 播放页标题不能被额外按钮挤坏

## 内容

- **长度限制**：
  - 对话场景（`kind !== 'passage' && kind !== 'jlpt'`）：每场严格 **5–8 句**，完成「开场 → 推进/转折 → 收束」完整闭环
  - 短文场景（`kind === 'passage'`）：每篇严格 **5–6 段**，每段 1–3 句
  - JLPT 听力（`kind === 'jlpt'`）：每场严格 **4–12 句**，包含题干提问、正文对话与选项解析
- **分类必填**：每个场景必须显式填写有效的 `category`（12 类之一：`work` / `shopping` / `medical` / `food` / `transport` / `home` / `admin` / `study` / `social` / `travel` / `service` / `opinion`），不保留 `focus` 字段
- **自然书写与假名标注**：
  - 严禁在日文正文（`line.ja`）中添加人为分词空格；按自然日文连写，确保 iOS 原生划词查词与 TTS 韵律自然
  - 所有日文汉字必须按语境用 `{漢字|かんじ}` 标注假名
  - 数字、日期、量词、人名、多音词重点核对
- 参考 Irodori / Minato / NHK Easy / JMdict / OJAD / BCCWJ 核对，但不得复制教材原文
- 不确定的表达或读音必须标出，不能硬猜
- 短文必须整篇连续显示，只高亮当前朗读句；高亮使用单一浅灰底，不要彩条
- 播放页右侧固定「AI 解析」栏（手机上从底部弹出，宽屏可与对话区拖动分栏）：用户粘贴自己的 Gemini key（只存 localStorage），在页面内直接提问；使用 Gemini Interactions API 的 previous_interaction_id 做服务端会话：第一次提问带上整场台词和当前句，后续只发送用户输入；换句再问时补一句当前句标记；对话 id 与消息按场景保存在 localStorage，重新打开可继续；场景台词或 key 变更、服务端会话过期时，用本地完整对话重建一次；不附加角色设定或回答模板；回答流式输出，先显示思考动画，可中途停止；不内置 key，不做 iframe 嵌套
- 已取消跳转外部 AI 平台（ChatGPT / Claude 等），保留精简后的页面内「问 AI」面板

## 音频

- 只用 Gemini 3.8 Flash TTS（无 `edge-tts` 回退）
- 声线直接写在 `scenarios.json` 的 `speakers[].voice` 中：不限死 `self: true` 的单一音色，各角色（含自己与对方）均按场景语境从 Gemini 官方 30 个预设音色中自由选择，同一场景内两个角色音色不重复
- 同一场景同一角色必须固定同一音色且声线稳定不跳，不能跨批次混音
- 合成时保留 `{漢字|かんじ}` 的语境读音控制（日期、数量词与易混多音词展开为标注读音，其余保持自然汉字连写）
- 对话场景优先走整场多角色一次合成后从无损 WAV 按自适应停顿切分，并校验每段时长与字数比（异常时自动回退逐句合成）；短文场景整篇一次合成后按段间停顿切分
- 所有产出音频统一经 `ffmpeg` 母带处理：裁掉首尾多余静音（保留 `60ms` 句尾余量）、统一 `-16 LUFS` 响度，并压制为 `24kHz` 单声道紧凑 MP3
- 播放端（`usePlayer`）在播放当前句时预加载下一句音频，配合首尾静音修剪实现平滑连续播放与无死寂单句循环
- `public/audio/manifest.json` 记录每句 `voice + ja` 哈希，`npm run check` 自动校验音频与台词哈希一致，改字或改声线必重录
- 单句循环只能包含当前句，不能混入相邻句
- 音频不齐或哈希不一致时不发布
- TTS key 不进入仓库、前端、日志或提交
- 多 key 轮换、限速、额度安全
